# Módulo Editar Licitación

## Descripción
Edición de licitaciones existentes con todos sus datos y productos.

## Archivos
- `editar_licitacion.html` - Formulario de edición
- `editar_licitacion.js` - Lógica de edición

## Funcionalidades
- ✅ Cargar datos existentes
- ✅ Modificar información
- ✅ Actualizar productos
- ✅ Gestionar alternativas
- ✅ Recalcular márgenes
- ✅ Guardar cambios

## API Endpoints
- `GET /api/licitaciones/:id`
- `PUT /api/licitaciones/:id`
