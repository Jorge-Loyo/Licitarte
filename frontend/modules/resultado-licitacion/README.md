# Módulo Resultado Licitación

## Descripción
Visualización de resultados y adjudicación de licitaciones.

## Archivos
- `resultado_licitacion.html` - Vista de resultados
- `resultado_licitacion.js` - Lógica de visualización

## Funcionalidades
- ✅ Ver productos adjudicados
- ✅ Comparar ofertas
- ✅ Registrar ganadores
- ✅ Motivos de pérdida
- ✅ Exportar resultado
- ✅ Generar reporte

## Información Mostrada
- Productos cotizados
- Precios ofertados
- Ganadores por ítem
- Análisis de competencia
- Márgenes obtenidos

## API Endpoints
- `GET /api/licitaciones/:id/resultado`
- `POST /api/licitaciones/:id/adjudicar`
