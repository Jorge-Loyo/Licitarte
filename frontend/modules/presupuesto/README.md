# Módulo Presupuesto

## Descripción
Generación y visualización de presupuestos para licitaciones.

## Archivos
- `presupuesto.html` - Vista de presupuesto

## Funcionalidades
- ✅ Ver presupuesto detallado
- ✅ Descargar PDF
- ✅ Enviar por email
- ✅ Imprimir

## Contenido del Presupuesto
- Datos de licitación
- Listado de productos
- Precios unitarios y totales
- Condiciones comerciales
- Vigencia de oferta

## API Endpoints
- `GET /api/presupuesto/:numero`
