# Módulo Administración

## Descripción
Gestión completa de datos maestros del sistema: clientes, oferentes, marcas, laboratorios, monodrogas, catálogo de productos y configuraciones.

## Archivos
- `administracion.html` - Vista principal con tabs
- `administracion.js` - Controlador principal
- `admin/` - Submódulos por entidad

## Funcionalidades
- ✅ CRUD de clientes con organismos
- ✅ CRUD de oferentes
- ✅ CRUD de marcas
- ✅ CRUD de laboratorios
- ✅ CRUD de monodrogas con búsqueda
- ✅ Catálogo de productos con paginación
- ✅ Tipos de licitación
- ✅ Organismos/Jurisdicción
- ✅ Portales/Origen
- ✅ Modalidades de entrega
- ✅ Formas de pago
- ✅ Motivos de pérdida
- ✅ Mantenimiento de oferta
- ✅ Carga masiva por Excel
