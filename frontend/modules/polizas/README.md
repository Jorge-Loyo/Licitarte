# Módulo Pólizas

## Descripción
Gestión de pólizas de garantía asociadas a licitaciones.

## Archivos
- `polizas.html` - Vista de pólizas

## Funcionalidades
- ✅ Listado de pólizas
- ✅ Filtros por estado
- ✅ Alertas de vencimiento
- ✅ Descargar documentos
- ✅ Actualizar estado

## Estados de Póliza
- Vigente
- Por vencer
- Vencida
- Ejecutada
- Devuelta

## API Endpoints
- `GET /api/polizas`
- `PUT /api/polizas/:id`
