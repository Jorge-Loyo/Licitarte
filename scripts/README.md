# Scripts - Utilidades

## Contenido

- **setup_dev.sh** - Setup de ambiente de desarrollo
- **setup_prod.sh** - Setup de ambiente de producción
- **backup_db.sh** - Backup de base de datos
- **migrate_db.sh** - Ejecutar migraciones

## Uso

```bash
# Desarrollo
bash scripts/setup_dev.sh

# Producción
bash scripts/setup_prod.sh

# Backup
bash scripts/backup_db.sh

# Migraciones
bash scripts/migrate_db.sh
```

## Nota

Scripts para Linux/Mac. Para Windows, usar .bat equivalentes.
